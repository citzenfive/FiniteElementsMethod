# Finite Element Methods

This repository contains Jupyter notebooks developed for a Numerical Analysis course focused on the Finite Element Method.

## Contents

* `MixedFiniteElementMethod.ipynb` — mixed finite element formulations and convergence studies.
* `HybridFiniteElementMethods.ipynb` — hybrid finite element methods, static condensation, and numerical experiments.
* `DiscontinuousGalerkin.ipynb` — discontinuous Galerkin formulation and convergence analysis.
* `HybridMixedFiniteElementMethods.ipynb` — hybrid mixed finite element methods, static condensation, and numerical experiments.

## Requirements

The notebooks use:

```bash
numpy
matplotlib
seaborn
```

## Running

Open the notebooks with Jupyter:

```bash
jupyter notebook
```

or

```bash
jupyter lab
```

Then run each notebook cell by cell.

## Topics

* Classical finite element methods
* Mixed finite element methods
* Hybrid finite element methods
* Discontinuous Galerkin methods
* Static condensation
* Error computation
* Convergence studies
